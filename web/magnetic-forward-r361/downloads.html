Run the simulation

The public GitHub Pages site runs the static interactive simulator. To run a downloaded copy locally, start a static file server in the web/magnetic-forward-r361 directory and open http://127.0.0.1:8767/:

python -m http.server 8767

No GPU or scientific Python packages are needed for the browser simulation. Do not use a file:// URL. Python model training and causal replay require a separate environment and do not run on GitHub Pages.

The public repository includes code, frozen research weights, selected de-identified prepared inputs, logs, protocol, aggregate evidence and papers. Original raw Trial streams with unresolved machine-path and acquisition metadata are withheld pending a separate release review. See data availability for scope and limitations.
