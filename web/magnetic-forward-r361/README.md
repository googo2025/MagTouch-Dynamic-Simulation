# MagTouch 磁响应正向实验室

打开同一文件夹中的 `index.html`。完全本地运行，无硬件连接、无在线服务、无第三方网页依赖。请保留离线包内全部文件在同一文件夹。

实验下拉框包含 30 条留出记录；可在分轴历史、联合历史基线与仅当前位置模型之间切换，查看五个节点的 15 通道实测／预测磁响应。默认使用新分轴历史研究模型。选择“交互生成”后调整 XYZ 或动作类型，按播放推进，再导出带来源标记的 CSV。

点击顶部“复杂轨迹与稀疏磁场研究”，或打开 `research.html`，可播放 60 条复杂单触头虚拟路径，查看随时间预测的 15 通道 ΔB，并导出整条 CSV。六类动作包括异相 XYZ、变压深回线、三维螺旋、随机分段、停驻反转、压入—滑动—撤出。这里“复杂多轨迹”是多条单触头轨迹，不是同时多点触碰。

同页第五项提供“四节点预测第五节点”的实测对照：切换源/目标代表记录、留出节点与方法，查看三轴实测和预测。训练期使用了源器件各已知节点的监督标签；推理只读另外四节点，不读指令位置和被预测节点。150 个配对评估对应 30 条记录 × 5 种留一节点设置，不代表 150 次独立采集。未测新空间位置、多高度场和多触点仍待独立验证。

直接操作：点击“自由按压”，在三维网格上按住左键并拖动，改变目标 XY。松开左键自动撤出；勾选“松开鼠标后保持按压”可维持压深。滚轮向上加深、向下减浅，或按 Shift 上下拖动；也可用“压入并保持”“撤出”“加深/减浅”按钮和 XYZ 滑块。右键拖动始终旋转视角，“旋转视角”模式下左键也旋转。

键盘：画布聚焦时方向键改变 X/Y，PageDown 加深、PageUp 减浅，空格切换按压/撤出，Escape 撤出。手势/滑块修改自动启动连续计算。目标限于 XY ±5.5 mm、Z −1 至 2.3 mm，实际动作以最高 2 mm/s 跟随，不瞬移；上方坐标显示实际生成位置，金色十字表示目标 XY。更改目标不清除磁响应历史，只有“从起点重播”才开始新序列。每段最多 300 秒，达到后先导出再重播。

若内嵌浏览器不弹出文件下载，导出按钮还会显示完整可复制文本。该备用入口已验证生成 1222 帧圆轨迹 CSV；下载文件落盘在内嵌浏览器中未确认。

输出为无载基线扣除后的 ΔB，单位 µT。绝对磁场还需提供对应 B0。三维图只画名义触头动作和节点响应，不画未经验证的空间磁力线或硅胶形变。

分轴历史的真实留出磁场 NRMSE 相比联合历史基线由源侧 37.20% 降至 25.31%、目标侧 65.24% 降至 54.87%。这些是磁响应预测指标，不是定位误差。小比例虚拟增强的真实 XYZ 定位尚未稳定优于仅真实训练，因此生成数据仅供研究，不是物理真值，不进入正式模型。界面保留较差结果和整体偏移诊断。全部目标器件与实测复杂 waypoint 路径未参与拟合或选参；这些旧记录以前曾被分析，不能重新称为前瞻性盲测。

物理仿真接口说明见 `physics_bridge_spec.json`。本地导入只用于查看；目前未附带通过实测验证的动态／多触点物理求解器。

有限元形变：下方独立查看器支持 `fem_bridge_spec.json` 所述的表面网格＋逐帧三维位移 JSON，可旋转、播放、逐帧查看、对照未变形轮廓和放大位移。颜色表示真实位移幅值，放大只改变显示。求解器、几何、材料、边界条件均须有来源记录。文件在浏览器本地解析，不上传。

该功能是有限元**结果查看器**，不是实时求解器。尚无经验证的当前成品完整形变结果随包提供；历史模型的几何、接触/预应力/材料记忆假设不直接冒充当前器件。不会凭经验磁场输出生成假形变，也不会将任意拖动动作与不同输入的预计算位移同步冒充耦合。实际实时形变仍需对接物理求解器或经过留出验证的形变代理。

工程内的完整实验说明位于 `analysis/r361_command_forward_20261001/README.md`。单独的网页离线包不包含全部原始磁场 CSV，不能代替完整工程的训练复现数据。

新研究结果与模型位于 `analysis/r363_complex_forward_20261001`、`analysis/r364_sparse_field_20261001`。在完整工程根目录，使用带 NumPy 的 Python 依次运行 `python -m training.forward_complex_r363`、`python -m training.sparse_field_r364` 即可重新训练回测；运行 `python -m unittest training.test_research_r363_r364` 检查因果性、状态重置和留出节点输入隔离。`tools/build_research_r363.py` 生成科学图和网页数据，`tools/export_forward_r361_web.py` 更新主网页回放数据。新脚本继承原始记录清单与文件哈希，不连接实验硬件。
